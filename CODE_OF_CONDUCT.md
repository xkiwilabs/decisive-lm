# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone
who takes part, in issues, pull requests, discussions or any other project space, is expected to follow it.

To report unacceptable behaviour, contact the maintainers at michael.j.richardson@mq.edu.au. Reports are handled in
confidence.
